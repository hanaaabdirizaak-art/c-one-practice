# Chapter 3: Making Decisions – C#

## 1. Decision Structures and if
Controls program execution using conditions.
Relational operators: >, <, >=, <=, ==, !=

## 2. if-else Statement
Executes one block when true and another when false.

## 3. Nested Decision Structures
Places one decision inside another.
if-else-if checks multiple conditions.

## 4. Logical Operators
- && AND
- || OR
- ! NOT

## 5. bool Variables and Flags
Stores true or false.
A flag indicates whether a condition exists.

## 6. Comparing Strings
Compares strings using ==, != and String.Compare.

## 7. TryParse
Converts user input safely.
Methods: int.TryParse, double.TryParse, decimal.TryParse.

## 8. Input Validation
Checks whether entered data is valid and within an acceptable range.

## 9. Radio Buttons and Check Boxes
- RadioButton: Selects one option.
- CheckBox: Selects multiple options.
- CheckedChanged: Detects selection changes.

## 10. switch Statement
Selects an action based on a value.
Uses case, break and default.

## 11. List Boxes
Displays and manages a list of items.
- Items.Add: Adds items.
- Items.Remove: Removes an item.
- Items.RemoveAt: Removes by index.
- Items.Clear: Removes all items.
- SelectedItem: Gets selected item.
- SelectedIndex: Gets selected index.

## Quick Revision
- if: One condition.
- if-else: Two alternatives.
- Nested if: Multiple decisions.
- Logical operators: Connect conditions.
- bool: True or false.
- TryParse: Safe conversion.
- Validation: Checks input.
- RadioButton: One choice.
- CheckBox: Multiple choices.
- switch: Multiple alternatives.
- ListBox: Displays items.
